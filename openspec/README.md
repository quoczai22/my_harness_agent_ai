# OpenSpec-style change records

Create one directory per change, for example `openspec/changes/2026-09-02-add-login/`, containing:

- `proposal.md` — motivation, scope, exclusions, risks.
- `design.md` — technical approach and decisions.
- `specs/requirements.md` — verifiable SHALL statements and scenarios.
- `tasks.md` — small implementation tasks with 2–6 technical keywords each.

Register the same tasks through Continuity Core before implementation.
