# Requirements

- The kit has a locally tested user supplied 1GB GGUF and checksum verified official 2GB, 3GB, and 4GB GGUF options.
- Each option passes a short local inference smoke test before being presented as usable.
- Chat, DOCX, and PDF use the same selected model and keep kit-relative paths.
- The 3GB option is the default for classroom use.
- No model is misrepresented by copying or renaming a different quantization.
- Existing learning and document files are preserved.

- A standalone 3GB folder contains only its selected model and works without the four-model kit.
