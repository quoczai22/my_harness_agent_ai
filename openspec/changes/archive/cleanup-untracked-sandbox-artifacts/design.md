# Design

Establish standard directories for managing workspace tasks:
- `tasks/active/`: Stores active work orders and in-progress task definitions.
- `tasks/archive/`: Stores summaries/records of reviewed and accepted tasks.

Relocate the root `TASK-ANTIGRAVITY-SANDBOX.md` file into `tasks/active/TASK-ANTIGRAVITY-SANDBOX.md` with unchanged contents. Update `AGENTS.md` to document the convention. Register the scoped task in Continuity and follow the reviewed workflow checkpoints.
