# Lite Terminal Kit

> **Status:** Deferred 2026-09-22, implementation never reviewed: PDF reading was split into lite-pdf-text-reader; archived during cleanup on 2026-11-09.

Create a USB-portable, terminal-only local coding assistant for weak Windows machines. It uses the supplied CPU llama.cpp binary bundle and Qwen2.5-Coder 1.5B Q4 GGUF model; no Ollama, VS Code, PATH, network, or admin installation is required.
