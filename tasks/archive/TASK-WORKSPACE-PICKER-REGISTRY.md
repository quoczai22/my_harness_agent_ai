# TASK-WORKSPACE-PICKER-REGISTRY

## Objective

Let the user choose any local project folder from Harness Atlas, remember it, and switch projects without restarting while preserving strict workspace isolation.

Render an evidence-derived Project Flow and an honest Harness execution flow as part of the active project's initial context.

Connect the installed official Antigravity CLI as a safe, explicit, quota-aware provider that returns chat and reviewable proposals without direct project writes.
